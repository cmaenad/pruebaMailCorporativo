# Prueba técnica de maquetación de email corporativo responsivo

Este repositorio es una prueba técnica de maquetación de un email corporativo responsivo.

## Arquitectura

- `index.html`: versión principal del email.
- Imágenes usadas por el email están en el mismo directorio.
- El diseño usa tablas anidadas para la estructura.

## Secciones del email

- Header: logo o título visual.
- Body: contenido principal con texto e imágenes.
- Footer: contacto, redes sociales o disclaimers.

## Restricciones

- Usar tablas anidadas para la estructura principal.
- Usar CSS inline para compatibilidad con clientes de correo.
- Asegurar que el contenido se vea bien en escritorio y móvil.
- Evitar frameworks complejos.
- Priorizar compatibilidad y legibilidad.
- Solo HTML y CSS puro, sin scripts ni animaciones.
